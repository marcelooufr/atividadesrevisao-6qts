atividades Aula 22/10

1- Algumas táticas são usar palavras-chave relacionadas ao assunto do site, criar títulos e descrições claros, produzir conteúdos originais e úteis, adicionar textos alternativos nas imagens e usar links entre páginas. Também é importante deixar o site rápido e adaptado para celulares, pois isso melhora a experiência dos usuários.

Referência: Google. Guia de SEO para iniciantes E conversion.com.br

2- Sim, o Materialize tem, ele permite criar sites responsivos usando um sistema de grid, colunas, breakpoints e classes que adaptam o layout conforme o tamanho da tela. Assim, o site consegue funcionar melhor em celulares, tabletsou computadores.

Referência: Documentação oficial do Materialize CSS

3- Escolhi o YouTube, que é um site que eu acesso bastante. Ele tem uma boa responsividade, pois adapta os vídeos, menus e imagens para diferentes tamanhos de tela. No celular, a navegação é simples e os vídeos se ajustam bem. Porém, dependendo do tamanho da tela, alguns textos e botões ficam pequenos ou muito grandes, mas atrapalha so na estetica, No geral, considero que ele é bem adaptado para diferentes dispositivos.
